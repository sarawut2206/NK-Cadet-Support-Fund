# ติดตั้งฐานข้อมูลกลาง (Google Sheets + Apps Script)

ฐานข้อมูลกลางเก็บ **ทะเบียนหนังสือเข้า–ออก** และ **บัญชีรับ–จ่าย** ของกองทุนไว้ใน Google Sheets
โดยมี Apps Script ทำหน้าที่เป็น API ให้หน้าเว็บ `ledger.html` เรียกใช้

```
เว็บไซต์ (GitHub Pages)  →  Apps Script Web App  →  Google Sheets
     ledger.html                  Code.gs            ฐานข้อมูลจริง
```

---

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 10 นาที)

### 1. สร้างสเปรดชีต
1. เปิด <https://sheets.google.com> สร้างสเปรดชีตใหม่
2. ตั้งชื่อว่า **ฐานข้อมูลกองทุนเตรียมทหาร 2569**

### 2. ใส่โค้ด
1. ในสเปรดชีตนั้น เลือกเมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` ทิ้งทั้งหมด
3. คัดลอกเนื้อหาไฟล์ [`Code.gs`](Code.gs) ในโฟลเดอร์นี้ไปวางแทน
4. **แก้บรรทัด `var TOKEN`** เป็นรหัสของตัวเอง เช่น
   ```js
   var TOKEN = 'nkcadet-8f3a2c-2569';
   ```
   จำรหัสนี้ไว้ ต้องนำไปกรอกในหน้าเว็บให้ตรงกัน
5. กด **บันทึก** (ไอคอนแผ่นดิสก์)

### 3. สร้างตาราง
1. กลับไปที่แท็บสเปรดชีต แล้ว **โหลดหน้าใหม่**
2. จะมีเมนูใหม่ชื่อ **กองทุนเตรียมทหาร** ขึ้นมาบนแถบเมนู
3. เลือก **กองทุนเตรียมทหาร → สร้าง/ซ่อมตารางฐานข้อมูล**
4. ครั้งแรกจะขออนุญาตเข้าถึงบัญชี Google ให้กด **อนุญาต**
   (หน้าจอเตือน "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด *ขั้นสูง* → *ไปที่ ... (ไม่ปลอดภัย)* เพราะเป็นสคริปต์ของเราเอง)
5. จะได้ชีต 4 ชีต: `ทะเบียนหนังสือ` `บัญชี` `ทะเบียนเลขที่` `บันทึกการใช้งาน`

### 4. เผยแพร่เป็น Web App
1. ใน Apps Script กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้ใหม่**
2. เลือกประเภทเป็น **เว็บแอป**
3. ตั้งค่า
   - **ดำเนินการในชื่อ** : ฉัน (บัญชีของคุณ)
   - **ผู้มีสิทธิ์เข้าถึง** : **ทุกคน**
4. กด **ทำให้ใช้งานได้** แล้ว **คัดลอก URL** ที่ลงท้ายด้วย `/exec`

> ทุกครั้งที่แก้โค้ด ต้องกด *ทำให้ใช้งานได้ใหม่* อีกครั้ง มิฉะนั้น URL เดิมจะยังใช้โค้ดเก่า

### 5. เชื่อมกับหน้าเว็บ
1. เปิด <https://sarawut2206.github.io/NK-Cadet-Support-Fund/ledger.html>
2. กดปุ่มสถานะการเชื่อมต่อมุมขวาบน
3. กรอก **URL** ที่คัดลอกมา, **รหัสเข้าใช้งาน** ที่ตั้งไว้ในข้อ 2.4 และ **ชื่อผู้บันทึก**
4. กด **บันทึกและทดสอบการเชื่อมต่อ** — ถ้าขึ้นสีเขียวว่าเชื่อมต่อสำเร็จ ถือว่าเสร็จ

## ความปลอดภัยและข้อจำกัด

**Web App นี้เปิดให้เรียกได้จากอินเทอร์เน็ต** เพราะหน้าเว็บบน GitHub Pages ต้องเรียกได้โดยไม่ต้องล็อกอิน Google
รหัสเข้าใช้งานกันคนทั่วไปได้ระดับหนึ่ง แต่เนื่องจากรหัสถูกเก็บไว้ในเบราว์เซอร์ของผู้ใช้ จึงไม่ใช่ระบบล็อกอินที่แท้จริง

**ห้ามบันทึกข้อมูลต่อไปนี้ลงฐานข้อมูลนี้**
- ข้อมูลสุขภาพของนักเรียน เช่น ผลคัดกรองตาบอดสี โรคประจำตัว
- เลขประจำตัวประชาชน
- ข้อมูลฐานะทางเศรษฐกิจรายบุคคล เช่น รายชื่อนักเรียนที่ขอทุนขาดแคลน

ข้อมูลกลุ่มนี้เป็นข้อมูลอ่อนไหวตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
ให้เก็บไว้ใน **สมุดบัญชีกองทุน (ไฟล์ Excel)** และแฟ้มเอกสารออฟไลน์เท่านั้น
เวลาบันทึกการจ่ายทุนลงฐานข้อมูลนี้ ให้ใส่ช่องคู่กรณีเป็นรหัสหรืออักษรย่อ เช่น `นร.041`

**ถ้าต้องการระบบล็อกอินจริง** ทางเลือกคือย้ายหน้าจอไปเป็น HTML ของ Apps Script เอง แล้วตั้งผู้มีสิทธิ์เข้าถึงเป็น
*ทุกคนภายในองค์กร* ซึ่ง Google จะบังคับล็อกอินให้ แต่จะเรียกจาก GitHub Pages ไม่ได้ ต้องเข้าผ่าน URL ของ Apps Script แทน

## หมายเหตุทางเทคนิค

- หน้าเว็บเรียก API ด้วยวิธี **JSONP** ผ่าน `doGet` เพื่อเลี่ยงปัญหา CORS ของ Apps Script
  จึงส่งข้อมูลได้ไม่เกินประมาณ 7,500 ตัวอักษรต่อครั้ง เพียงพอสำหรับหนึ่งรายการเสมอ
- การลบรายการ **ไม่ลบแถวจริง** แต่ทำเครื่องหมาย `ยกเลิก` ตัดยอดเป็นศูนย์ และขีดฆ่าในสเปรดชีต
  เพื่อให้เลขที่เอกสารเรียงต่อเนื่องและตรวจสอบย้อนหลังได้
- ทุกการเพิ่ม แก้ไข และยกเลิก บันทึกไว้ในชีต `บันทึกการใช้งาน` พร้อมเวลาและชื่อผู้ทำ
- เลขที่เอกสารอัตโนมัติเก็บตัวนับไว้ในชีต `ทะเบียนเลขที่` แยกตามประเภทและปี
  ขึ้นปีการศึกษาใหม่ให้แก้ `var YEAR` ในโค้ด แล้ว *ทำให้ใช้งานได้ใหม่*
- ใช้ `LockService` กันการเขียนชนกันเมื่อมีหลายคนบันทึกพร้อมกัน

## การสำรองข้อมูล

สเปรดชีตนี้คือฐานข้อมูลตัวจริง **สำรองทุกสิ้นเดือน** โดย
ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx) แล้วเก็บไว้อีกที่หนึ่ง
หรือใช้ ไฟล์ → ประวัติเวอร์ชัน เพื่อย้อนดูการแก้ไขย้อนหลัง
