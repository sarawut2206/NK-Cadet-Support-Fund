# ศูนย์เอกสารแผนเตรียมทหาร — โรงเรียนมัธยมวัดหนองแขม

เว็บไซต์ส่วนกลางสำหรับ **จัดทำและพิมพ์เอกสาร** ของแผนการเรียนเตรียมทหาร–ตำรวจ
โรงเรียนมัธยมวัดหนองแขม
443 ถนนเลียบคลองภาษีเจริญฝั่งใต้ แขวงหนองแขม เขตหนองแขม กรุงเทพมหานคร 10160 · โทร. 02-429-3402

เปิดใช้งานที่ <https://sarawut2206.github.io/NK-Cadet-Support-Fund/>

## เอกสารที่พิมพ์ได้

**งานกองทุน**
1. บันทึกข้อความ ขออนุมัติใช้เงินกองทุน — คำนวณขั้นการอนุมัติตามวงเงินให้อัตโนมัติ
2. แบบคำขอรับการสนับสนุนจากกองทุน
3. ใบสำคัญรับเงินทุนการศึกษา — แปลงจำนวนเงินเป็นตัวอักษรให้อัตโนมัติ
4. หนังสือขอบคุณผู้บริจาค
5. ใบประกาศเกียรติคุณผู้บริจาค (แนวนอน)

**งานนักเรียน**
6. แบบบันทึกผลทดสอบสมรรถภาพ 8 สถานี — ตรวจผ่าน/ไม่ผ่านให้อัตโนมัติ
7. แบบคัดกรองสุขภาพและความยินยอมของผู้ปกครอง
8. หนังสือยินยอมการเก็บและเผยแพร่ข้อมูลและภาพ (PDPA)
9. แบบวิเคราะห์ผลสอบเสมือนรายบุคคล — จัดกลุ่ม A–D ให้อัตโนมัติ

## วิธีใช้

1. กด **ตั้งค่าโรงเรียน** กรอกชื่อผู้อำนวยการและหัวหน้าแผน ครั้งเดียวพอ
2. เลือกเอกสารจากรายการทางซ้าย
3. กรอกข้อมูล ตัวอย่างเอกสารทางขวาจะเปลี่ยนตามทันที
4. กด **พิมพ์เอกสาร** ตั้งขนาดกระดาษ A4 และปิด “หัวกระดาษและท้ายกระดาษ”
   เลือก “บันทึกเป็น PDF” เพื่อเก็บไฟล์แทนการพิมพ์ก็ได้

ข้อมูลที่กรอกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น
**ไม่มีการส่งข้อมูลออกไปที่เซิร์ฟเวอร์ใด ๆ** และไม่มีฐานข้อมูลกลาง

## หมายเหตุ

- ใบสำคัญรับเงินทุน **มิใช่** ใบเสร็จรับเงินบริจาค ใบเสร็จรับเงินบริจาคต้องออกโดยงานการเงินของโรงเรียนตามระเบียบของทางราชการเท่านั้น
- เกณฑ์สมรรถภาพและโครงสร้างคะแนนในเอกสารเป็นเกณฑ์เป้าหมายของแผนการเรียน สำหรับการสอบจริงให้ยึดระเบียบการฉบับทางการของแต่ละเหล่าในปีที่สอบเสมอ
