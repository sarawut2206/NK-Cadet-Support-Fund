# ส่งคะแนนหลังเรียนขึ้น Google Sheets

1. สร้าง Google Sheets ใหม่ (ชื่ออะไรก็ได้) แล้วเลือก ส่วนขยาย → Apps Script
2. ลบโค้ดเดิม วางโค้ดจาก `Code.gs` แล้วแก้ `SECRET` เป็นรหัสของคุณเอง
3. กด ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   (ทุกคนที่รู้ URL ส่งได้ แต่ต้องมีรหัส `SECRET` ถึงจะเขียนชีตได้)
4. อนุญาตสิทธิ์เมื่อ Google ถาม แล้วคัดลอก URL ที่ลงท้าย `/exec`
5. เปิดหน้า fitness.html → ส่วนผลทดสอบวิชาการ → กด **ตั้งค่า Google Sheets** วาง URL และรหัส
6. กด **ส่งคะแนนขึ้น Google Sheets** (ส่งทับทั้งแท็บ "คะแนนหลังเรียน" ทุกครั้ง)

ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่ จึงจะมีผล
URL และรหัสถูกเก็บใน localStorage ของเบราว์เซอร์เครื่องครูเท่านั้น ไม่อยู่ใน repo
